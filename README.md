# atmos.

A calm, responsive weather search that helps you find current conditions for cities around the world. Search for a place, choose the matching location, and get a quick snapshot of its weather.

## Features

- Search cities and choose between matching locations.
- View current conditions, temperature, feels-like temperature, humidity, wind, and visibility.
- Responsive layout with loading, empty, and error states.
- Keyboard-friendly search and location selection.

## Built with

React, CSS, and the OpenWeather geocoding and current weather APIs.

## Run locally

```bash
npm install
npm start
```

The app opens at [http://localhost:3000](http://localhost:3000).
